# Ril. 408.0051 – Lernkarten

Webbasierte Lernkarten-Anwendung zum Lernen und Wiederholen von Begriffen und Inhalten aus der Richtlinie 408.0051.


## Hinweis

Dieses Projekt dient ausschließlich als Lern- und Übungshilfe und ersetzt nicht die jeweils gültigen offiziellen Regelwerke und betrieblichen Anweisungen.
